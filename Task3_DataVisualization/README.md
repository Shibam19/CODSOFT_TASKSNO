# 📊 Task 3: Data Visualization Dashboard

## 🎯 Objective

The objective of this task is to create meaningful and interactive data visualizations using Python libraries to better understand the Regional Sales Dataset. Various charts are designed to identify trends, compare performance, and communicate insights effectively through visual storytelling.

---

## 🛠️ Tools & Technologies Used

- 🐍 Python
- 🐼 Pandas
- 📊 Matplotlib
- 📈 Seaborn
- 📓 Jupyter Notebook

---

## 📂 Dataset

- **Dataset Name:** Regional Sales Dataset
- **Dataset Used:** Cleaned_Regional_Sales.csv

---

## 📊 Visualizations Created

✔️ Monthly Sales Trend (Line Chart)

✔️ Sales by Channel (Bar Chart)

✔️ Sales Distribution by Currency (Pie Chart)

✔️ Top 10 Products by Sales (Horizontal Bar Chart)

✔️ Warehouse Performance (Bar Chart)

✔️ Sales Distribution (Histogram)

✔️ Order Quantity Distribution (Histogram)

✔️ Unit Price vs Line Total (Scatter Plot)

✔️ Correlation Heatmap

✔️ Top 10 Highest Sales Orders (Bar Chart)

✔️ Dashboard Summary (Key Performance Indicators)
